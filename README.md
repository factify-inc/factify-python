# Factify Python SDK

Python SDK for the Factify API.

> **Note:** This SDK is auto-generated by [Speakeasy](https://www.speakeasy.com/). The initial generation will replace this README with full documentation.

## Setup

This repository is set up to automatically generate the Python SDK when the OpenAPI specification is updated.

### Required Secrets

The following secrets must be configured in the repository settings:

- `SPEAKEASY_API_KEY` - Speakeasy API key for SDK generation
- `SDK_PUBLISH_GH_TOKEN` - GitHub token with write access to this repository
- `PYPI_TOKEN` - PyPI API token for publishing the package

### Triggering Generation

The SDK generation is triggered by:

1. **Repository dispatch** from the mono repo when `openapi.json` changes
2. **Manual workflow dispatch** from the Actions tab
