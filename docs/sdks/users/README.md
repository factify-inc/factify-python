# Users

## Overview

User profile and account information.

### Available Operations

* [get_me](#get_me) - Get current user

## get_me

Returns the authenticated user's profile and organization memberships. Only available for user accounts (JWT auth), not API keys.

### Example Usage

<!-- UsageSnippet language="python" operationID="getMe" method="get" path="/v1beta/me" -->
```python
from factify import Factify


with Factify(
    bearer_auth="<YOUR_BEARER_TOKEN_HERE>",
) as f_client:

    res = f_client.users.get_me()

    # Handle response
    print(res)

```
